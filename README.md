# DCC-BOGOTA (app-dccReports)

App Flutter + Firebase para la Defensa Civil Colombiana (seccional
Bogotá): reporte público de emergencias, mapa, despliegue organizado de
voluntarios/funcionarios/líderes y panel administrativo embebido en la
misma app.

Empieza por [`lineamientos/README.md`](lineamientos/README.md) — qué es
el proyecto, metodología de trabajo (Spec-Driven Development) y
estructura del repositorio.

```bash
flutter pub get
flutter run
```
