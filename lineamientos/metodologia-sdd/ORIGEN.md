# Origen de estas plantillas

Los archivos de esta carpeta (`AGENTS.template.md`, `spec-template.md`,
`prompts.md`, `sdd.excalidraw`) son copia de la carpeta `samples/` del
repositorio del curso **Hello SDD** de [MoureDev](https://moure.dev):

- Repositorio: <https://github.com/mouredev/hello-sdd>
- Curso (video): <https://youtube.com/live/5HaOxAAA5qI>
- Licencia del repositorio original: Apache License 2.0

Se guardan aquí tal cual (con `AGENTS.md` → `AGENTS.template.md` y
`spec.md` → `spec-template.md` renombrados solo para no confundirlos con
el `AGENTS.md` y los `specs/*/spec.md` propios de AmiPets) como
referencia rápida del flujo de Spec-Driven Development (SDD) que sigue
este proyecto — ver [`README.md`](README.md) de esta carpeta para el
resumen aplicado a AmiPets.
